เธอเก็บเครื่องประดับไว้ในกล่อง

 เธอเก็บเครื่องประดับ
She puts away the jewelry.

เธอ = she; you

เก็บ = to keep; to put away; to store

เครื่องประดับ = jewelry; ornament

  • เครื่อง = item; object
  • ประดับ = to adorn; to decorate

 ไว้ในกล่อง
In a box for safekeeping.

ไว้ = to keep; to set aside
ใน = in; inside
กล่อง = box

She stores the jewelry in a box.
